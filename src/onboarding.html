Configuration — Let Trade Copieur

Trois étapes, une seule fois. Aucune donnée ne quitte ton ordinateur.
Étape 1 — Ta clé Edge

Colle ta clé de licence

Tu la trouves sur let-tradejournal.com/copieur (bouton « Copier »).

Étape 2 — Connecte Tradovate

Branche tes comptes

Une petite extension Chrome capte ta session Tradovate (aucun mot de passe à saisir). Installe-la en un clic depuis le Chrome Web Store.

✓ J'ai ouvert la page Chrome Web Store de l'extension.
  1. Clique « Ajouter à Chrome », puis « Ajouter l'extension ».
  2. Reviens sur ton onglet Tradovate et rafraîchis la page (Cmd+R / Ctrl+R).
En attente de tes comptes… — suis les 2 étapes ci-dessus
Étape 3 — Ton groupe

Quels comptes tradent ensemble ?

Plus de compte maître : chaque ordre passé dans le Copieur part sur tous les comptes cochés en même temps. Tu pourras cocher/décocher et régler la taille de chacun plus tard.
